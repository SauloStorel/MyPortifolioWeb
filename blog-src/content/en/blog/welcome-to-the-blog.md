Hi, I'm Saulo.

## Who I am

I'm 20 and I live in Teresina, in Piauí, Brazil. I've liked programming since I was a kid. My uncle, who is also a programmer, is a great inspiration to me in many ways in my life, including professionally. Since I was little I watched him work and, sometimes, I went with him to the company's office.

I started programming with a book from Casa do Código, [*Lógica de Programação: Crie seus primeiros programas usando JavaScript e HTML*](https://www.casadocodigo.com.br/products/livro-programacao) (Programming Logic: Create your first programs using JavaScript and HTML), by Paulo Silveira and Adriano Almeida, and it was my uncle, in fact, who gave me that book.

That book was my first learning in programming. It teaches programming logic with JavaScript and HTML, using everyday situations: conditions (`if`), loops (`for` and `while`) and functions. It also uses the HTML Canvas to create drawings and animations with code.

Later I took courses in JavaScript, React and programming logic. They were all recommendations I received along the way.

Right now I'm in my first job, which is actually an internship, at the FMS in Teresina (the city's Municipal Health Foundation). I work in the HR department as a systems developer, and I take care of the whole HR system of the FMS and its branches.

At the internship, I work on new features and maintenance for the FMS HR system. There I've learned a lot in practice, like code organization and teamwork. There is code review and there are challenges every day, where I learn more and more about solving new problems.

Outside the internship I run Storell, which is my work building websites and systems, almost always with Ruby on Rails.

## What I've built

- [DeMolay Piauí](/en/projects/demolay-piaui/): the Order's website, with a registration store, InfinitePay payments, a transparency portal, check-in and event certificates.
- [CRN Cap](/en/projects/crn-cap/): the system for the Order's CRN and CNIE campaigns, with five access profiles and a ranking.
- [Xfria](/en/projects/xfria/): an ESP32 that imitates the air conditioner's remote control, so you can use it from your computer and phone.
- [rhut](/en/projects/rhut/): screen sharing for Discord straight from the browser.
