    Como eu penso request → response

    Do request ao response: cada camada do Rails com uma responsabilidade só.

    1. GET /projetos

      Navegador

      O pedido chega ao servidor.

    2. config/routes.rb

      Rotas

      resources :projects aponta para o controller certo.

    3. ProjectsController#index

      Controller

      Só orquestra. Regra de negócio densa vai para um service object.

    4. Project.includes(:tags)

      Model e PostgreSQL

      Busca com includes, sem N+1, reusando scopes.

    5. index.html.erb

      View e Turbo

      Renderiza HTML; o Turbo troca só o que mudou.

    6. 200 OK

      Resposta

      De volta ao navegador, coberto por specs.
